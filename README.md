# TemUES - Aplicación de Comercio Electrónico C2C Universitario

**TemUES** es una plataforma de comercio electrónico de tipo **Consumer-to-Consumer (C2C)** diseñada específicamente para la comunidad universitaria. Su objetivo principal es conectar a estudiantes emprendedores con potenciales compradores dentro de la misma institución, fomentando un entorno de confianza, cercanía y apoyo al emprendimiento estudiantil.

## 📌 Propósito del Proyecto

La aplicación busca fortalecer la economía interna de la universidad y facilitar la colaboración entre compañeros. Permite que cualquier estudiante pueda actuar tanto como comprador como vendedor de manera ágil y sin complicaciones, eliminando las barreras de entrada para los pequeños negocios universitarios.

## 🚀 Funcionalidades Principales

- **Perfil Dual (Comprador/Vendedor):** Todo usuario puede navegar para comprar o crear su propio catálogo de productos para vender.
- **Descubrimiento Inteligente:** Inicio adaptado a los intereses del usuario y búsqueda avanzada por categorías o palabras clave.
- **Comunicación Integrada:** Mensajería instantánea en tiempo real para negociar y resolver dudas.
- **Contacto Directo:** Botón de llamadas telefónicas integrado para facilitar la comunicación inmediata.
- **Gestión de Catálogo:** Herramientas para que los vendedores publiquen ofertas, actualicen precios y gestionen sus productos fácilmente.

## 🛠️ Stack Tecnológico e Implementaciones

Para lograr una experiencia de alta calidad, el proyecto integra las siguientes librerías y funcionalidades:

### 🔹 Infraestructura y Backend (Firebase)
- **Firebase Authentication:** Gestión segura de acceso para la comunidad estudiantil.
- **Cloud Firestore:** Base de datos en tiempo real para productos y mensajes.
- **Firebase Storage:** Almacenamiento multimedia para fotos de productos.
- **Firebase Cloud Messaging (FCM):** Notificaciones push para nuevas ventas o mensajes.
- **Firebase Crashlytics:** Monitoreo y reporte de errores para estabilidad.

### 🔹 Interfaz de Usuario (UI/UX)
- **Material Design Components:** Interfaz moderna, limpia y consistente.
- **Lottie:** Animaciones interactivas para mejorar la experiencia de usuario.
- **Jetpack Navigation:** Flujo de navegación intuitivo entre pantallas.
- **Swipe Layouts:** Interacciones gestuales para una navegación fluida.

### 🔹 Multimedia y Hardware
- **CameraX:** Integración con la cámara para capturar fotos de productos.
- **Glide:** Carga eficiente y optimizada de imágenes desde la nube.
- **Audio:** Funcionalidad para intercambio de notas de voz o sonidos en la app.
- **Llamadas:** Integración con el sistema telefónico del dispositivo.

### 🔹 Datos y Machine Learning
- **Room Database:** Persistencia de datos local para acceso sin conexión (caché).
- **Retrofit + Gson:** Consumo de APIs externas y procesamiento de datos JSON.
- **TensorFlow Lite:** Implementación de IA para adaptar la aplicación a los intereses y gustos del usuario.

### 🔹 Otros
- **Stripe:** Pasarela de pagos para transacciones seguras dentro de la plataforma.
- **Wifi & Network State:** Gestión del estado de conexión para una experiencia sin interrupciones.
